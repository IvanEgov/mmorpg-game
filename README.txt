# 🎮 Dungeon Chronicles: 2D MMORPG

Легковесная браузерная 2D MMORPG с видом сверху, созданная на чистом JavaScript (Vanilla JS), HTML5 Canvas и Firebase Realtime Database. Игра не требует установки и работает прямо в браузере, поддерживая как ПК, так и мобильные устройства.

🔗 **Играть онлайн**: [https://ivanegov.github.io/mmorpg-game/](https://ivanegov.github.io/mmorpg-game/)

---

## ✨ Особенности игры

### ⚔️ Геймплей и Боевая система
- Плавное перемещение и анимированные атаки с визуальными эффектами (слэши, вспышки).
- Всплывающие числа урона и динамические HP-бары над персонажами и врагами.
- Умный ИИ врагов: преследование игрока, соблюдение минимальной дистанции и анимация атаки.

### 📈 Прогрессия и Экипировка
- Система уровней, опыта и очков для распределения характеристик (Сила, Ловкость, Интеллект, Живучесть).
- Дерево навыков с пассивными бонусами.
- **6 слотов экипировки**: Оружие, Шлем, Нагрудник, Штаны, Обувь, Кольцо. Каждый предмет влияет на итоговые статы.
- Инвентарь с поддержкой стаков предметов и глобальное хранилище в городе.

### 🌍 Мир и Локации
- **Стартовый город**: NPC с диалогами, магазины, система квестов и хранилище.
- **Подземелья**: Локации с врагами (Слаймы, Летучие мыши), которые пересоздаются при каждом входе.
- **💀 Арена выживания**: Бесконечный режим на большой карте. Камера следует за игроком. Волны врагов появляются каждые 15 секунд, их количество и сила масштабируются каждые 3 уровня героя. Система смерти с штрафом (-20% золота) и возрождением в городе.

### 🌐 Мультиплеер (Онлайн)
- Синхронизация позиций и статусов игроков в реальном времени через **Firebase Realtime Database**.
- Умная система сессий: каждый браузер/вкладка имеет уникальный ID (через `sessionStorage`), что предотвращает появление "клонов" одного игрока.
- Плавная интерполяция движения других игроков.

### 📱 Кроссплатформенность
- Полная поддержка мобильных устройств: виртуальный джойстик, адаптивный интерфейс и кнопки действий на экране.
- Автоматическое сохранение прогресса (инвентарь, статы, квесты, золото) в `localStorage`.

## 📁 Структура проекта

Проект имеет модульную архитектуру для легкого масштабирования:

```text
morpg-game/
├── index.html                  # Точка входа, разметка UI и экранов
├── style.css                   # Стили интерфейса, анимации и адаптивность
├── README.md                   # Этот файл
└── js/
    ├── main.js                 # Инициализация игры и обработка экрана входа
    ├── core/
    │   ├── Game.js             # Главный игровой цикл, рендер, камера, управление состоянием
    │   ├── Camera.js           # Логика плавного следования камеры за игроком
    │   └── UIManager.js        # Управление HTML-панелями (инвентарь, статы, магазины)
    ├── entities/
    │   ├── Player.js           # Логика, статы, инвентарь и экипировка игрока
    │   ├── PlayerRenderer.js   # Визуальная отрисовка игрока и его оружия
    │   ├── Enemy.js            # Базовая логика и ИИ врагов
    │   ├── EnemyRenderer.js    # Визуальная отрисовка врагов
    │   ├── OtherPlayer.js      # Логика сетевого игрока (интерполяция)
    │   ├── OtherPlayerRenderer # Отрисовка других игроков в сети
    │   ├── NPC.js              # Логика неигровых персонажей
    │   └── Portal.js           # Логика порталов между локациями

    │   ├── Location.js         # Базовый класс локации
    │   ├── CityLocation.js     # Генерация города, NPC и порталов
    │   └── DungeonLocation.js  # Генерация подземелий и Арены выживания
    ├── systems/
    │   └── WaveManager.js      # Логика волн, спавна и масштабирования сложности на Арене
    ├── network/
    │   └── NetworkManager.js   # Подключение к Firebase, отправка и получение данных
    └── data/
        └── constants.js        # Глобальные настройки: размеры, цвета, базы данных предметов и врагов

🚀 Как запустить локально
Клонируйте репозиторий:
   git clone https://github.com/ivanegov/mmorpg-game.git
   cd mmorpg-game
Откройте папку в редакторе кода (например, VS Code).
Используйте расширение Live Server (или любой другой локальный сервер, например python -m http.server), чтобы открыть index.html.
⚠️ Просто открыть файл двойным кликом может не сработать из-за политик безопасности браузеров (CORS).
⚙️ Настройка Firebase (для Мультиплеера)
Чтобы онлайн-режим работал, необходимо настроить свою базу данных:
Перейдите в Firebase Console.
Создайте новый проект (например, mmorpg-game).
В левом меню выберите Realtime Database → Создать базу данных.
Выберите режим "Начать в тестовом режиме" (Test mode).
Перейдите на вкладку Правила (Rules) и замените код на:
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
(Нажмите "Опубликовать")
6. Перейдите в Настройки проекта (шестеренка) → вкладка Общие → раздел "Ваши приложения" → иконка Web (</>).
7. Скопируйте объект firebaseConfig.
8. Откройте файл js/network/NetworkManager.js и замените заглушку конфигурации на вашу:
   const firebaseConfig = {
       apiKey: "ВАШ_API_KEY",
       authDomain: "ВАШ_ПРОЕКТ.firebaseapp.com",
       databaseURL: "https://ВАШ_ПРОЕКТ-default-rtdb.europe-west1.firebasedatabase.app",
       // ... остальные поля
   };
🎮 Управление
💻 ПК
WASD или ЦФЫВ — Перемещение
Пробел или ЛКМ — Атака
E или У — Взаимодействие (NPC, порталы)
I или Ш — Инвентарь
C или С — Характеристики и экипировка
K или Л — Навыки
Esc — Закрыть любое меню
📱 Мобильные устройства
Левый нижний угол: Виртуальный джойстик для движения.
Правый нижний угол: Кнопка атаки (⚔️).
Верхний правый угол: Кнопки меню (🎒 Инвентарь, 📊 Статы, 🌳 Навыки, 💬 Диалог).
🛠️ Технологический стек
Frontend: HTML5, CSS3, Vanilla JavaScript (ES6+)
Графика: HTML5 Canvas API (2D Context)
Backend / Сеть: Firebase Realtime Database
Хостинг: GitHub Pages
Хранение: LocalStorage & SessionStorage
